# Example

## Tracklist
- 00:00 - Artist - Song
- ...




1. Run ./bin/author/blank-mix.sh, then write the description and tracklist as - 00:00 — Artist - Song.
2. Run ./bin/author/push-mix.sh mixes/<mix>.md --audio mix.mp3 --cover cover.jpg. It uploads the mix and writes the Mixcloud address and cover into the file.
    -   Rerun it without --audio to push later edits to the title, description or tracklist. That replaces what's on Mixcloud.
    - Add --dry-run to see what it would send. All 8 of your current mixes pass a dry run.
3. Commit, then run deploy.sh. The build stops if a mix hasn't been pushed to Mixcloud yet.
